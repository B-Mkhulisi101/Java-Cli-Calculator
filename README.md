# Java-Cli-Calculator
 A command-line calculator built using Java as part of my learning journey. This is my first project while learning Java, designed to practice core concepts like loops, conditionals, and user input validation.

## Features
- Performs basic arithmetic: Addition ('+'), Subtraction ('-'), Multiplication ('*') and Division ('/').
- Loops continuously using a do-while loop until the user decides to exit.
- Basic input validation (e.g., prevents entering 0 as an operand).
- Uses a switch statement to handle different operations.

## How to Run
1. Ensure you have Java installed (`javac -version`).
2. Compile the code using:
   javac Calculator.java
Run the program:
    java Calculator
